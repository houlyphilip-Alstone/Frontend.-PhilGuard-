PHILGUARD API · V1

Build secure email into your application.

A developer-first REST API for protected email records, usage tracking and auditable access.

Quick start

Authenticate each API request with a project API key. Never expose live keys in browser code or source control.

curl -X POST https://YOUR_API_DOMAIN/v1/secure-email \
-H "Authorization: Bearer YOUR_API_KEY" \
-H "Content-Type: application/json" \
-d '{"email":"customer@example.com","project_id":"YOUR_PROJECT_ID"}'

Authentication

Use a Bearer token in the Authorization header. Keys should be scoped to a project and rotated when compromise is suspected.

POST /v1/secure-email

Encrypt and store an authorised email record.

{
  "email": "customer@example.com",
  "project_id": "proj_8f21"
}

POST /v1/decrypt-email

Decrypt a record only when the authenticated caller has permission to access it.
